Cómo Insertar una Imagen en HTML

Guía paso a paso para añadir imágenes a tu página o aplicación web utilizando enlaces de Internet.

1

Buscar la imagen en la web

El primer paso es navegar hasta el sitio web donde se encuentra la imagen que deseas utilizar en tu proyecto.

Página web de ejemplo:
https://mariainescarvajal.wordpress.com/2011/05/20/un-ejemplo/

Abre el enlace en una pestaña de tu navegador para ver el contenido donde está alojada la imagen.

2

Obtener la dirección directa de la imagen

Para que el código HTML funcione, no debemos usar la dirección de la página completa, sino la dirección directa del archivo de imagen:

  1. Posiciónate con el puntero del mouse justo sobre la imagen elegida.
  2. Haz clic con el botón derecho del mouse.
  3. En el menú desplegable, selecciona la opción "Copiar dirección de imagen" (o "Copy image address" en inglés).
Enlace directo copiado (URL de la imagen):
https://mariainescarvajal.wordpress.com/wp-content/uploads/2011/05/dove.jpg
💡 ¿Cómo reconocer que es el link correcto?
El enlace directo de una imagen generalmente termina con una extensión de archivo gráfico, por ejemplo: .jpg, .jpeg, .png, .webp o .gif.
3

Pedirle a la IA que inserte la imagen que está en ese link

En lugar de escribir código HTML manualmente, mediante Vibe Coding simplemente le indicamos a la Inteligencia Artificial (Gemini, Claude, ChatGPT, etc.) que inserte la imagen utilizando el enlace directo que acabamos de copiar.

💬 Ejemplo de prompt para pedirle a la IA:
"Por favor, insertá en mi aplicación la imagen que está en este link: https://mariainescarvajal.wordpress.com/wp-content/uploads/2011/05/dove.jpg. Asegurate de incluir una descripción para accesibilidad y que la imagen sea adaptativa (responsive) para que se adapte bien a pantallas de celular y computadora."

A partir de tu indicación, la IA generará e insertará en el archivo HTML el código con la etiqueta <img> y el atributo src="...", quedando así:

HTML 
<img src="https://mariainescarvajal.wordpress.com/wp-content/uploads/2011/05/dove.jpg" 
     alt="Paloma de la paz - Ejemplo" 
     style="max-width: 100%; height: auto;">

Partes de la etiqueta <img>:

Atributo Función Ejemplo en este tutorial
src (source) Ruta o dirección URL donde está guardada la imagen. "https://.../dove.jpg"
alt (alternative text) Texto descriptivo que se muestra si la imagen no carga y para personas con discapacidad visual (accesibilidad). "Paloma de la paz - Ejemplo"
style / dimensiones Permite controlar el ancho y alto para que se adapte bien a pantallas de celular y computadora. max-width: 100%; height: auto;
4

¡Resultado final en vivo!

Así es exactamente como se visualiza la imagen del ejemplo una vez insertada en una página web:

Vista previa en tiempo real

Imagen cargada directamente desde: dove.jpg

Resumen de buenas prácticas:

  • Usa siempre el enlace directo a la imagen (terminado en .jpg, .png, etc.), no la dirección de la página web.
  • Incluye siempre el atributo alt con una breve descripción para accesibilidad.
  • Añade style="max-width: 100%; height: auto;" para que tu imagen sea responsive y no se desborde en celulares.
